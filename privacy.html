개인정보처리방침

시행일: 2026년 11월 7일

  1. 사용 범위: channel-ops는 운영자 본인만 사용하는 개인용 도구입니다.
  2. 접근하는 정보: 운영자 본인의 YouTube 채널 정보와, 운영자가 업로드하는 영상·썸네일·자막·영상 설정입니다. Google 사용자 데이터는 운영자 본인 채널의 영상 업로드와 설정 목적으로만 사용합니다.
  3. 저장: 로그인 토큰은 운영자 본인 컴퓨터의 보안 저장소(macOS 키체인)에만 저장하며, 외부 서버로 보내거나 제3자와 공유하지 않습니다.
  4. 판매·광고: 어떤 데이터도 판매하거나 광고에 사용하지 않습니다.
  5. 삭제: 운영자는 언제든 Google 계정 설정의 '타사 액세스'에서 이 앱의 권한을 해제할 수 있으며, 그러면 저장된 토큰은 쓸 수 없게 됩니다.

channel-ops의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube API 사용은 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.

Privacy Policy (summary): channel-ops is used only by its owner. It accesses only the owner's YouTube channel data to upload and configure the owner's videos. Tokens are stored only in the owner's macOS Keychain, never sent to other servers, shared, or sold. Use of Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
